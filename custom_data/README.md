# Custom data

`custom_data_v1.zip` Release Asset (또는 외부 다운로드 링크)에 500장의 검수 완료 자체 수집 제품 이미지, CVAT box/transcription XML, DET 라벨, REC 라벨을 포함한다. 원본은 JPEG 최대 긴 변 1600px로 압축했고 XML 좌표도 같은 비율로 변환했다.

`validation_214/`은 학습에 사용하지 않은 별도 실사 검증 214장과 `labels.csv`를 포함한다. 파일별 출처·제품군·source sampling 정보는 이 저장소의 `metadata/` CSV에 남긴다.
